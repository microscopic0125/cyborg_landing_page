# CYBR//01 Landing Page

A futuristic cyberpunk-inspired landing page built with plain HTML, CSS, and JavaScript. The design blends neon UI styling, sci-fi typography, immersive hero visuals, and animated loading effects to create a high-tech "human × machine" aesthetic.

## Overview

This landing page is designed for brands, startups, or creative portfolios that want a bold, futuristic first impression. It includes:

- Animated loading screen
- Futuristic navigation bar
- High-contrast hero section with cybernetic visuals
- About section with terminal-style content
- Feature cards for core systems
- Futuristic contact CTA and access panels
- Responsive layout for desktop and mobile devices

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts (Orbitron + Space Grotesk)

## Run Locally

Because this is a static site, you can open the page directly in a browser or run a local server.

### Option 1: Open directly

Open `index.html` in your browser.

### Option 2: Local server

From this folder, run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customization

You can personalize the landing page by editing the following sections:

- Hero headline and description in `index.html`
- System cards and content blocks in `index.html`
- Colors, glow effects, spacing, and layout in `style.css`
- Animation timing and interactivity in `script.js`

## Notes

The page includes a sample hero image located in `images/cyborg3.jpg`. You can replace it with your own image by updating the `src` attribute in the hero section or by substituting the file in the `images/` folder.
